# Proofread Mode

## Governing constraint

**Only fix what is objectively wrong.** Spelling, grammar, and punctuation errors that any competent editor would flag the same way. Leave voice, diction, tone, sentence structure, and register untouched, even where a style critique would object to them. That's transform's job, not this one.

## What counts as an error

- Misspellings and typos.
- Subject-verb agreement, verb tense, and pronoun agreement.
- Homophone misuse: its/it's, there/their/they're, your/you're, affect/effect.
- Comma splices, run-ons, and missing sentence-ending punctuation.
- Misplaced or missing apostrophes.
- Doubled words, or a dropped word that breaks the grammar (not just the rhythm).

## What is not an error

- Fragments, comma splices used for deliberate effect, dialect, or a narrator's voice.
- Word choice, sentence length, register, or rhythm, even where you'd write it differently.
- Anything house style would flag elsewhere (em dashes, hedging, blocklist diction). Not this mode's job; see `references/house-style.md` if that's what's wanted instead.
- Quoted speech reproducing how a person actually talks.

## Procedure

1. Read the whole piece before touching anything. The same construction reads as an error or as voice depending on context, a fragment mid-dialogue is the latter.
2. Mark only what's objectively wrong under the definitions above.
3. Fix each in place, minimally, at the smallest scope that resolves it. Don't rewrite the sentence around a fix.
4. Where a fix is ambiguous (the intended meaning isn't recoverable from context), make the more conservative choice and flag it in one line rather than picking silently.
5. Return the corrected text only. If nothing needed fixing, say so instead of returning an unchanged copy.

## Rules

- Never change a claim, fact, name, number, or the argument's order while fixing an error nearby.
- No profile, no craft dimensions, no voice, no house style. This mode ignores all of them; it corrects, it doesn't restyle.
